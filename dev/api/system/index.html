Core: System (PowerfulCore)

System construction, per-unit conversion, configuration and topology. Islands and outages are on Islands and Outages. These names are defined in PowerfulCore.System and exported by PowerfulCore; most are re-exported by Powerful.

Module

PowerfulCore.System — Module

System module - High-level system operations for Powerful.jl

This module provides:

  • SystemBuffers: Workspace for residual evaluation
  • Per-unit conversion utilities
  • Topology analysis (island detection, AMD ordering)
  • Configuration system (SimulationConfig, settings loading)

System Construction

PowerfulCore.Foundation.SystemModel — Type
SystemModel(case::PowerFlowData.Network, model_types=nothing;
            system_base=100.0,
            frequency_base=case.caseid.basfrq, constant_power_vmin=0.7)

Convenience constructor to create a SystemModel from a PowerFlowData case.

Arguments

  • case: PowerFlowData Network object (from parse_network)
  • model_types: Optional tuple/vector of model types. If nothing (default), uses all_models()
  • system_base::Float64=100.0: System base power in MVA (the models are converted to per-unit on this base)
  • frequency_base::Float64: System frequency in Hz (default: the case's base frequency)
  • constant_power_vmin::Float64=0.7: Voltage (pu) below which constant-power load is reduced smoothly to zero (see constant_power_factor)

The system-wide settings (sys.settings, a SystemConfig) hold the frequency base, the MVA base (system_base) and the constant-power breakpoint; every analysis of the system uses them.

DAE addresses are assigned per problem, not here: pass addressing (e.g. AMDAddressing()) to ACPowerFlowProblem or TDSProblem.

Workflows

Default Workflow (with per-unit conversion)

using Powerful
using PowerfulCases

case = parse_network(load("ieee14").raw)
sys = SystemModel(case)  # Auto-converts to per-unit on 100 MVA base

# Access original data (preserved automatically)
sys.parsed_data.models.PQ.pl[1]  # → 21.7 MW (original)
sys.models.PQ.pl[1]              # → 0.217 pu (computational)

# Use different system base
sys = SystemModel(case; system_base=500.0)  # 500 MVA base

# Use AMD addressing for better sparse factorization
prob = ACPowerFlowProblem(sys; addressing=AMDAddressing())

Explicit Workflow (Maximum Control)

# For advanced users who need full control over each step
case = parse_network(load("ieee14").raw)
models, order = ext2int(load_models(case, all_models()))
external_pre = retrieve_external_params(models, models, order, PrePerUnit)
parsed = ParsedSystemData(models, 100.0)
result = convert_system_to_per_unit(parsed.models, parsed.system_base, external_pre)
external_post = retrieve_external_params(result.models, result.models, order, PostPerUnit; pu_coeffs = result.coeffs)
sys = SystemModel(result.models, merge_external(external_pre, external_post), order;
                  settings=SystemConfig(), parsed_data=parsed, pu_coeffs=result.coeffs)

See Also

  • ParsedSystemData: Container for original data
  • convert_system_to_per_unit: Per-unit conversion
  • load_models: Parse models from case

PowerfulCore.System.add_instances! — Method
add_instances!(sys::SystemModel, additions::NamedTuple) -> SystemModel

Append model instances to sys, e.g. add_instances!(sys, (Fault = faults,)). Instances must already be in per-unit. Models not yet in the system are added.

The system is re-indexed with ext2int (so group references to the added models resolve everywhere), external parameters are retrieved for the extended models, and the cached topology is invalidated. Errors if an added instance key already exists, or appears twice in additions; sys is left unchanged on error.

PowerfulCore.System.derive_system — Method
derive_system(sys::SystemModel, keep::AbstractDict, new_models::NamedTuple; drop_empty=false,
              links=ModelLinks()) -> SystemModel

A new system derived from sys: keep the instances selected by keep (see filter_instances, including drop_empty), add new_models, re-index the merged model set with ext2int, and retrieve external parameters for new_models against it. Kept instances keep their external parameters, original parsed data and per-unit coefficients, filtered with the same masks, and the derived system keeps the settings of sys. sys is not modified. The external parameters of new_models retrieved before the per-unit conversion (PrePerUnit) hold the physical value, as in sys (recovered from the per-unit models through the coefficients).

new_models are per unit on the system base, except those that declare a rating from the device they are linked to (ModelRating(...; from = LinkedDevice())): their parameters are per unit on that device's base, and are converted here, with links (ModelLinks) naming the devices of sys (which keep may remove) they are linked to (convert_linked_models). Their coefficients join the system's pu_coeffs.

Shared by every derived-system builder, such as the TDS system builder (static models plus dynamic models) and any other that assembles a system from a different mix of models.

System Buffers

PowerfulCore.System.SystemBuffers — Method
SystemBuffers(::Type{T}, am::AddressManager, sys::SystemModel, formulation::FormulationTrait) where T

Construct system workspace with all model workspaces pre-allocated.

Iterates through all models in the system, creates a ResidualBuffers for each using formulation-specific metadata. This function performs ALL memory allocation - subsequent residual evaluations are zero-allocation.

The array type (CPU vs GPU) is inferred from the model data. Use to_gpu(sys) to transfer the system to GPU before creating workspaces.

Arguments

  • T: Float type for calculations
  • am: AddressManager with formulation-specific addresses
  • sys: SystemModel containing model vectors; the system-wide settings come from sys.settings
  • formulation: PowerInjection() or CurrentInjection()
  • hold, hold_x: Held values of out-of-service own variables and zero-mass states (optional); pass those of the Float64 workspace to share them with a workspace of another element type
  • automata: Model name → AutomatonState to share (optional; nothing: new ones); pass those of the Float64 workspace (automaton_states): a workspace of another element type shares their modes and discrete quantities and holds its memory and values in its own element type (AutomatonState(state, T))
  • typed_fields: Model name → fields whose columns the evaluators read from a copy of element type T instead of the system's (optional), so that values of type T (e.g. parameters as Dual numbers) can be written there; the other columns are shared

Returns

  • SystemBuffers: Fully allocated workspace ready for calculations

Example

# Create problem which sets up infrastructure
prob = ACPowerFlowProblem(sys, CurrentInjection())
# SystemBuffers created internally

PowerfulCore.System.evaluate_generator_contributions! — Method
evaluate_generator_contributions!(sys_ws::SystemBuffers{T}, y::AbstractVector{T}, status::Dict{Symbol, Vector{Bool}}) where T

Evaluate generator contributions (reactive power injections) after power flow converges.

This cold-path function uses scatter_residuals_accumulate! instead of scatter_residuals!, which skips :set mode and allows generator control equations (PV voltage control, Slack power balance) to accumulate their contributions instead of replacing bus power balance equations. This enables extraction of actual reactive power injections from generators.

Implementation

Uses _eval_models_accumulate! which calls scatter_residuals_accumulate! for each model. This treats SharedRes(:set) as :add during scatter, allowing control equations to contribute to power balance instead of overwriting it.

Physical Interpretation

After power flow converges, residuals g = 0. With accumulate-only scatter:

  • For PV generators: g[bus_Q] = actual Q injection to maintain V = Vs
  • For Slack generators: g[busP] and g[busQ] = actual P and Q injections

Arguments

  • sys_ws: Pre-allocated system workspace
  • y: Converged solution vector (from power flow)
  • status: Dict{Symbol, Vector{Bool}} with active status for each model

Returns

  • g: Residual vector containing generator contributions at bus injection positions

Example

prob = ACPowerFlowProblem(sys)
sol = solve(prob, Newton())
ws = setup_powerflow_newton(prob)
status = build_status_dict(sys)
g_gen = evaluate_generator_contributions!(get_float_ws(ws.adcache), sol.dae.y, status)

See Also

  • evaluate_system_residuals!: Base residual evaluation function
  • scatter_residuals_accumulate!: Cold-path scatter that skips :set mode
  • get_generator_residuals: Lazy accessor for cached generator contributions in PowerFlowSolution

PowerfulCore.System.evaluate_system_residuals! — Method
evaluate_system_residuals!(sys_ws, f, g, x, y, status, t; recorder=nothing)

DAE-based API for residual evaluation with differential states, at time t.

This interface supports time-domain simulation where models have both differential states (x) and algebraic variables (y), producing both differential residuals (f) and algebraic residuals (g).

Arguments

  • sys_ws::SystemBuffers: Pre-allocated workspace
  • f::AbstractVector: Differential residual vector (dx/dt contributions)
  • g::AbstractVector: Algebraic residual vector
  • x::AbstractVector: Differential state vector
  • y::AbstractVector: Algebraic variable vector
  • status::Dict{Symbol, Vector{Bool}}: Active status for each model (required)
  • t: Time of the state (x, y) (required: a model's residuals can depend on it directly)
  • recorder: Optional InjectionRecorder for tracking model contributions

Implementation

For each model:

  • If model has differential states: gather from both x and y, scatter to both f and g
  • If model is algebraic-only: gather from y, scatter to g (same as power flow)

Example

# TDS problem with dynamic models
prob = TDSProblem(setup_tds(sol_pf, dynamic_models))
adcache = create_adcache(prob.address_manager, sys, prob.formulation, ForwardDiffBackend())

# Evaluate DAE residuals
x = zeros(n_diff)  # Differential states
y = zeros(n_alg)   # Algebraic variables
f = zeros(n_diff)  # Differential residuals
g = zeros(n_alg)   # Algebraic residuals
status = build_status_dict(sys)

adcache(f, g, x, y, status, t)  # Uses this method internally

PowerfulCore.System.hold_out_of_service! — Method
hold_out_of_service!(sys_ws, f, g, x, y, status)

Replace every own algebraic residual row a of an out-of-service instance by g[a] = y[a] - hold[a], and the row of each own zero-mass state by f[a] = x[a] - hold_x[a]. Called by evaluate_system_residuals! after all models are evaluated (whose evaluator closures record in sys_ws.out_of_service which models have out-of-service instances, so the pass is free when every instance is in service), so the row keeps an equation (its Jacobian row is the identity) although the instance contributes nothing. Errors if an out-of-service instance belongs to a model whose own rows cannot be held, or if the held values were never set.

PowerfulCore.System.refresh_external! — Method
refresh_external!(sys, model::Symbol, field::Symbol)

The external parameters retrieved from field of model are copies, taken when the system was built: after an event changed the field they are copied again, in place (the arrays the models' workspaces hold), as they were taken. A parameter retrieved after the per-unit conversion (PostPerUnit) is a copy of the per-unit field. One retrieved before it (PrePerUnit) holds the physical value, which the model now holds per unit: the physical value is recovered through the per-unit coefficient of the field (sys.pu_coeffs, which converted it), as it is at the build of the system and of the systems derived from it. A field that no model declares as a parameter to convert (an index, a base voltage) was not converted, and is copied as it is. An ArgumentError names a field that is converted and has no coefficient in sys, whose physical value cannot be recovered.

PowerfulCore.System.retrieve_external_params — Method
retrieve_external_params(models_to_retrieve, all_models, index_order, phase)

Retrieve external parameters for specified models at the specified phase.

External parameters are model properties that reference other models (e.g., PQ needs bus.ide from Bus). Retrieval happens in two phases:

  • PrePerUnit: Before per-unit conversion (dimensionless params like bus type, indices)
  • PostPerUnit: After per-unit conversion (physical quantities already in per-unit)

Arguments

  • models_to_retrieve: NamedTuple of models to retrieve external parameters FOR
  • all_models: NamedTuple of all models (provides lookup context for references)
  • index_order: IndexOrder containing foreign_refs for indexing
  • phase: RetrievalPhase type (PrePerUnit or PostPerUnit)
  • pu_coeffs: for PrePerUnit retrieval from all_models that are already per unit (a system derived from a built one), the per-unit coefficients of the system (sys.pu_coeffs, or nothing where it has none): a parameter that reads a converted field holds the physical value, as one retrieved before the conversion does. missing (default): the values are copied as they are. For PostPerUnit, the coefficients of the models retrieved for (convert_system_to_per_unit, derive_system), where the derived parameters (RatingRatio) of their metadata are kept.

Returns

  • NamedTuple with same keys as models_to_retrieve, values are NamedTuples of external param arrays

Example

# TDS case: retrieve for dynamic models, but lookup in all models (including Bus)
external = retrieve_external_params(
    dynamic_models,  # Only GENCLS
    all_models,      # GENCLS + Bus + Branch + etc.
    index_order,
    PrePerUnit
)
# Result: (GENCLS=(Bus_v=[...], Bus_a=[...]), ...)

# Normal case: retrieve for all models
external = retrieve_external_params(models, models, index_order, PrePerUnit)

PowerfulCore.System.ParsedSystemData — Type
ParsedSystemData

Simple container for preserving original parsed data (physical units) before per-unit conversion.

This is an optional container - you only need it if you want to preserve the original physical unit data alongside the per-unit computational model.

Fields

  • models::NamedTuple: Original model StructArrays in physical units (MW, MVAR, kV)

# Parse and store original

PowerfulCore.System.convert_linked_models — Method
convert_linked_models(sys, new_models, links) -> (models = NamedTuple, coeffs = NamedTuple)

Per-unit conversion of the models among new_models that declare a rating from the device they are linked to (LinkedDevice): their parameters are given per unit on that device's base (for a converter, its MBASE), and are converted to the system base of sys through the same coefficients as any model's (calc_pu_coefficients, with the linked device's rating as Sn), which coeffs returns for sys.pu_coeffs. links (ModelLinks) link their instances to the devices of sys. The other models are returned as they are (they are per unit on the system base already), and have no entry in coeffs. A rating that cannot be resolved is an ArgumentError (linked_device_ratings).

PowerfulCore.System.convert_system_to_per_unit — Method
convert_system_to_per_unit(models::NamedTuple, system_base::Float64)

Convert all models in a system to per-unit values using metadata-driven conversion.

This is the high-level API for per-unit conversion. It automatically:

  • Extracts metadata for each model type
  • Calculates conversion coefficients based on device ratings and external references
  • Converts models that have parameters requiring conversion (PQ, PV, Transformer2W)
  • Passes through models already in per-unit (Bus, Branch)

Arguments

  • models::NamedTuple: Named tuple of model StructArrays (e.g., from load_models)
  • system_base::Float64: System base power in MVA
  • external::NamedTuple: Pre-retrieved external parameters from retrieveexternalparams(PrePerUnit)

Returns

  • Named tuple with fields:
    • models::NamedTuple: Models converted to per-unit
    • coeffs::NamedTuple: Per-unit conversion coefficients for inverse conversion (pu → physical)

Example

using PowerfulCases
using Powerful

# 1. Parse case (physical units: MW, MVAR, kV)
case = parse_network(load("ieee14").raw)
models = load_models(case, all_models())

# 2. Convert to per-unit (on 100 MVA base); `external` comes from
#    retrieve_external_params(..., PrePerUnit), see `SystemModel(case)`
result = convert_system_to_per_unit(models, 100.0, external)
models_pu = result.models
coeffs = result.coeffs  # Stored for inverse conversion in reports

Per-Unit Conversion Details

For PSS/E format:

  • PQ loads: pl, ql, ip, iq (PowerPU), yp, yq (AdmittancePU) converted
  • PV generators: pg, qg (PowerPU) converted using mbase rating
  • Transformers: r12, x12 (ImpedancePU) converted using sbase1_2 rating
  • Branches: Already in system per-unit, passed through unchanged
  • Buses: No conversion needed (provides base voltage reference)

PowerfulCore.System.TopologyInfo — Type
TopologyInfo

Network topology analysis results.

Fields

  • n_islands::Int: Number of disconnected islands
  • island_map::Vector{Int}: Maps bus internal index → island number (1-based)
  • slack_buses::Vector{Int}: Slack bus internal index per island
  • adjacency::SparseMatrixCSC{Bool, Int}: Bus connectivity matrix
  • components::Vector{Vector{Int}}: Bus internal indices per island
  • incidence::Union{Nothing, SparseMatrixCSC{Int8, Int}}: Branch-bus incidence matrix (L×N)
    • Row l has +1 at from-bus, -1 at to-bus for branch l
    • Only includes active (in-service) 2-terminal devices
    • Used for PTDF/LODF computation and deriving B matrices

    • is_bridge[l] = true if removing edge l disconnects the graph
    • Used for N-1 contingency pre-screening

    • Includes ALL 2-terminal devices (Branch, Transformer, TCSC, etc.) via Terminal trait

    • branch_indices[l] = (:Transformer, 3) means row l is Transformer instance 3

Example

for l in findall(topo.is_bridge)
    model_name, instance_idx = topo.branch_indices[l]
    println("Bridge: $model_name instance $instance_idx")
    # model_name ∈ {:Branch, :Transformer, :TCSC, ...}
end

# Incidence matrix for PTDF computation
A = topo.incidence  # L×N sparse matrix

PowerfulCore.System.analyze_topology — Method
analyze_topology(sys::SystemModel; vertex_model::Symbol=:Bus) -> TopologyInfo

Analyze power system topology to identify islands and connectivity.

Uses the Terminal API (getterminals) to generically discover connectivity from all models in the system. The vertex model must carry a bus type code ide (the slack vertex of an island has `ide == BUSSLACK`).

Algorithm

  1. Build adjacency matrix by querying all models for their terminals
  2. Filter by device status (only active devices)
  3. Run connected components algorithm (BFS)
  4. Identify slack/reference vertex per island (or warn if missing)

Arguments

  • sys::SystemModel: System to analyze
  • vertex_model::Symbol=:Bus: Vertex model to analyze

Returns

TopologyInfo containing islands, connectivity, and slack buses

Example

sys = SystemModel(case)

# Analyze AC topology
topo = analyze_topology(sys)  # Defaults to :Bus
println("Found $(topo.n_islands) AC islands")

Caching

# Cache in SystemModel for reuse
sys.topology = analyze_topology(sys)

# Or use analyze_topology! to cache automatically
analyze_topology!(sys)  # Sets sys.topology

PowerfulCore.System.build_incidence_matrix — Function
build_incidence_matrix(sys::SystemModel, vertex_model::Symbol=:Bus) -> SparseMatrixCSC{Int8, Int}

Build the branch-bus incidence matrix A (L×N) for all active 2-terminal devices.

Structure

  • L rows = number of active 2-terminal devices (branches, transformers, etc.)
  • N columns = number of vertices (buses)
  • Row l has +1 at from-bus column, -1 at to-bus column

Usage

The incidence matrix enables efficient computation of:

  • Bus susceptance matrix: B = A' D A where D = diag(1/x_l)
  • PTDF: PTDF = D · A · B⁻¹ (via sparse solves, never explicit inverse)
  • LODF: Derived from PTDF
  • Adjacency matrix: adj = (A' * A) .!= 0 (derived, not primary)

Returns

  • SparseMatrixCSC{Int8, Int}: Incidence matrix with values {-1, 0, +1}
  • Also returns branch_indices::Vector{Tuple{Symbol, Int}} mapping row l to (modelname, instanceidx)

Example

A, branch_idx = build_incidence_matrix(sys)
# A[5, :] has +1 at from-bus, -1 at to-bus for branch 5
# branch_idx[5] = (:Branch, 3) means row 5 corresponds to Branch instance 3

PowerfulCore.System.get_partition_after_outage — Method
get_partition_after_outage(topo, edge_idx) -> NamedTuple

Compute connected components after removing an edge.

For contingency screening, identifies which buses become isolated or form new islands when an edge is disconnected. Works correctly even if the original system has multiple islands.

Arguments

  • topo::TopologyInfo: Topology from analyze_topology(sys; build_incidence=true)
  • edge_idx::Int: Row index in incidence matrix (1-based)

Returns

NamedTuple with:

  • is_split::Bool: True if removal increases the number of islands
  • new_islands::Vector{Vector{Int}}: All islands after edge removal
  • n_new_islands::Int: Number of islands after removal
  • affected_islands::Vector{Int}: Indices of islands that were split (in new_islands)
  • smaller_affected::Int: Index of smallest affected island, or 0 if not split

Example

topo = analyze_topology(sys; build_incidence=true)

result = get_partition_after_outage(topo, 5)
if result.is_split
    # Get the smallest newly-created island
    isolated_buses = result.new_islands[result.smaller_affected]
    println("Removing edge 5 isolates buses: $isolated_buses")
end

Algorithm

Recomputes connected components on the adjacency matrix with the specified edge virtually removed. O(V+E) time complexity.
