Y-Bus Model Interface (PowerfulYbus)

Traits and functions through which models take part in the Y-bus formulation: their network partition role, nonconforming load type, admittance contributions and residuals.

Network Partition Roles

PowerfulYbus.FixedNetworkElement — Type
FixedNetworkElement <: NetworkPartitionRole

Marker for network elements that contribute constant (or topology-dependent) admittance.

Characteristics

  • Contribute to Y matrix at construction time
  • No state-dependent admittance changes during simulation
  • Only change Y matrix when topology changes (line trip, transformer tap)

Models with this role

  • Branch (transmission lines)
  • Transformer (with fixed or per-topology tap position)
  • Shunt (fixed capacitor/reactor banks)
  • Fault (contributes large shunt admittance during fault-on topology)

Example Y Contribution

Y_ij -= y_series        # Off-diagonal (negative of series admittance)
Y_ii += y_series + y_shunt_i   # Diagonal at from-bus
Y_jj += y_series + y_shunt_j   # Diagonal at to-bus
source
PowerfulYbus.MachineWithInternalVoltage — Type
MachineWithInternalVoltage <: NetworkPartitionRole

Marker for synchronous machines modeled with internal voltage behind reactance.

Characteristics

  • Generator contributes admittance Y_gen = 1/(ra + jxd') or 1/(ra + jxd") to Y diagonal
  • Provides E_internal = |E| * exp(j*delta) for network solution
  • Network current computed via: I = Ygg * Einternal
  • Electrical power: P + jQ = E * conj(I)

Models with this role

  • GENCLS: Classical model with xd' (transient reactance)
  • GENROU: Round-rotor with xd" (subtransient reactance)
  • GENSAL: Salient-pole with xd" (subtransient reactance)
  • GENTPJ1: Type-J machine model with xd" (its xq" may differ: the stator current is a machine variable, so the Norton source E = V + (ra + jxd")I is exact for any xq")

The admittance uses the subtransient reactance xd" when the machine model provides one (GENROU, GENSAL, GENTPJ1), falling back to the transient reactance xd' for models that only have one (GENCLS).

See Also

  • get_internal_voltage: Returns E_internal from state variables
source
PowerfulYbus.NetworkPartitionRole — Type
NetworkPartitionRole

Abstract type for classifying models by their role in Y-bus network formulation.

Subtypes

  • FixedNetworkElement: Elements that contribute constant admittance (Branch, Shunt, Transformer)
  • MachineWithInternalVoltage: Generators with transient/subtransient reactance (GENCLS, GENROU, GENSAL, GENTPJ1)
  • NonConformingLoad: Loads and current sources iterated by the network Newton solve (PQ, converters)
  • StaticGenerator: Power flow generators without a dynamic model (PV, Slack)
  • NotInYBusFormulation: Controllers and other non-network elements (TGOV1, SEXS)
  • UnsupportedInYBus: Models the Y-bus formulation does not represent, with the reason

Every model declares its role (network_partition_role): there is no default.

Network Solution

The network equations are solved at every bus by a sparse Newton iteration (solve_network!):

  • Generators contribute Y = 1/(ra + j*xd') to the diagonal and a Norton current
  • Non-conforming loads and current sources are nonlinear current injections
  • Static generators are constraints at their buses

See Also

  • network_partition_role: Query a model's partition role
  • NCLoadType: Sub-classification for non-conforming loads
source
PowerfulYbus.NonConformingLoad — Type
NonConformingLoad <: NetworkPartitionRole

Marker for loads that don't conform to simple constant-admittance representation.

Characteristics

  • Require Newton iteration to solve for bus voltage
  • Current depends nonlinearly on voltage: I = I(V)
  • A current injection of the network Newton solve (nc_load_current), except the constant-impedance part of a load, which is in Y

Models with this role

  • PQ: the constant-power and constant-current parts of its ZIP load, I(V) (its constant-impedance part is in Y)
  • Converters (REGCA1, REGFM_A1): current sources of their power Pe + j Qe at the terminal voltage

Sub-classification

Each declares how its current enters the network Newton iteration (NCLoadType):

  • VoltageDependentNCLoad: a current of the bus voltage, with its Jacobian (PQ)
  • CurrentSourceNCLoad: a current its states give (the converters)

See Also

  • NCLoadType: Sub-classification for Newton behavior
  • nc_load_type: Query specific NC load type
source
PowerfulYbus.NotInYBusFormulation — Type
NotInYBusFormulation <: NetworkPartitionRole

Marker for models that don't participate in network formulation.

Characteristics

  • No admittance contribution to Y matrix
  • No current injection into network
  • Typically controllers or auxiliary models

Models with this role

  • TGOV1: Governor (provides Pm to generator, doesn't inject current)
  • SEXS: Exciter (provides Efd to generator, doesn't inject current)
  • REECA1: Renewable electrical control (provides the current commands of REGCA1)
  • Area, Zone, Owner (AreaInterchange, Zone, Owner): data without equations

Note

These models still participate in TDS via their residual equations, but they don't appear in the network Y matrix or current balance.

source
PowerfulYbus.StaticGenerator — Type
StaticGenerator <: NetworkPartitionRole

Marker for power flow generators left static in the TDS system (instances without a dynamic model that replaces them).

Characteristics

  • Hold their bus as in the phasor TDS formulation: a PV generator keeps its active power pg and voltage magnitude vs (reactive power free); a Slack generator keeps the bus voltage vs∠va
  • Constraints in the network solve (their bus is retained), not admittances or current injections

Models with this role

  • PV, Slack
source
PowerfulYbus.UnsupportedInYBus — Type
UnsupportedInYBus <: NetworkPartitionRole

Marker for models the Y-bus formulation does not represent: YBusTDSProblem refuses a system holding one, naming it and reason (check_ybus_support).

Models with this role

  • VoltagePlayback: it holds its bus voltage to a recording, which the network solve does not impose, and its breaks are events of the TDS problem

A three-phase model (phase_representation) declares no role: the Y-bus simulation is positive sequence and refuses it by its phase representation.

source
PowerfulYbus.check_ybus_support — Method
check_ybus_support(sys)

Throw an ArgumentError naming each model of sys the Y-bus formulation cannot build: a model that declares no phase representation (phase_representation), a three-phase model (the Y-bus formulation is positive sequence), a positive-sequence model that declares no role (network_partition_role), with the roles it can declare, a model with instances whose role is UnsupportedInYBus, with its reason, and a NonConformingLoad that declares no load type (nc_load_type), with the types it can declare. Called first when the Y-bus buffers are built, before any role is read.

source

PowerfulYbus.network_partition_role — Function
network_partition_role(::Type{<:AbstractModel}) -> NetworkPartitionRole

Return the network partition role a model type declares.

Every positive-sequence model (phase_representation) declares its role: there is no default. Building the Y-bus buffers refuses a system holding a model without a role, naming it (check_ybus_support).

Implementation

Models declare their role here:

network_partition_role(::Type{<:Branch}) = FixedNetworkElement()
network_partition_role(::Type{<:GENCLS}) = MachineWithInternalVoltage()
network_partition_role(::Type{<:PQ}) = NonConformingLoad()
network_partition_role(::Type{<:TGOV1}) = NotInYBusFormulation()
network_partition_role(::Type{<:VoltagePlayback}) = UnsupportedInYBus("why")

Usage

role = network_partition_role(GENCLS)
if role isa MachineWithInternalVoltage
    # This generator adds its admittance 1/(ra + j*x) to Y (`_add_generator_contributions!`)
    # and provides E_internal (`get_internal_voltage`)
end

Nonconforming Loads

PowerfulYbus.CurrentSourceNCLoad — Type
CurrentSourceNCLoad <: NCLoadType

A source whose current its states give: I = (Ip - j Iq) e^{jθ} at the angle θ of the current iterate of its terminal voltage, gathered into the CurrentSourceBuffer (get_source_current_components). The converters: the REGCA1 family and REGFM_A1 (its current behind XL).

source
PowerfulYbus.NCLoadType — Type
NCLoadType

How a non-conforming load's current enters the network Newton iteration, as the model declares it (nc_load_type):

  • VoltageDependentNCLoad: a current the model computes from its bus voltage, with its Jacobian (PQ)
  • CurrentSourceNCLoad: a current its states give (REGCA1, REGFM_A1)

See Also

  • NonConformingLoad: The parent partition role
  • nc_load_type: Query a model's NC load type
source
PowerfulYbus.VoltageDependentNCLoad — Type
VoltageDependentNCLoad <: NCLoadType

A load whose current is a function of its bus voltage, iterated with its Jacobian by the network Newton solve: the model implements nc_load_current and nc_load_current_jacobian (and, if some instances inject nothing outside Y, injects_nonlinear_current). PQ: the constant-power and constant-current parts of its ZIP load (calc_load_current, with the constant-power breakpoint); its constant-impedance part is in Y.

Admittances and Residuals

PowerfulYbus.get_internal_voltage — Function
get_internal_voltage(ws::ResidualBuffers, model::StructArray, idx::Int) -> Complex

Return the internal voltage E_internal for generator idx.

Required for

Models with network_partition_role(M) == MachineWithInternalVoltage().

Returns

Complex: E_internal = |E| * exp(j*delta) in system reference frame

Computation

For a synchronous machine:

E_internal = E_q * exp(j*delta)

where:

  • E_q is the internal voltage magnitude (from algebraic state)
  • delta is the rotor angle (from differential state)

Usage

Internal voltages are gathered into a vector E and used in:

I_gen = Y_gg * E_internal

Example Implementation

function get_internal_voltage(ws::ResidualBuffers, model::StructArray{<:GENCLS}, idx::Int)
    E_q = ws.var_vals.E_q[idx]
    delta = ws.var_vals.delta[idx]
    return E_q * cis(delta)  # cis(x) = cos(x) + i*sin(x)
end

Note

The workspace ws contains gathered variable values that are current for the present timestep after gather_variables! has been called.

source
PowerfulYbus.nc_load_current — Function
nc_load_current(model::StructArray, idx::Int, v_r, v_i, vmin) -> (i_r=..., i_i=...)

Current drawn (consumption convention) by the part of load idx that is not a constant admittance in Y, at the rectangular bus voltage v_r + j v_i.

Required for

Models with network_partition_role(M) == NonConformingLoad() whose nc_load_type is VoltageDependentNCLoad, together with nc_load_current_jacobian and, if some instances inject nothing outside Y, injects_nonlinear_current.

Arguments

  • vmin: The system's constant-power breakpoint (sys.settings.constant_power_vmin)

Example Implementation (PQ, in network_injections.jl)

nc_load_current(model::StructArray{<:PQ}, idx, v_r, v_i, vmin) =
    calc_load_current(v_r, v_i, model.pl[idx], model.ql[idx], model.ip[idx],
                      model.iq[idx], zero(v_r), zero(v_r), vmin)  # Z part is in Y
source
PowerfulYbus.nc_load_current_jacobian — Function
nc_load_current_jacobian(model::StructArray, idx::Int, v_r, v_i, vmin) -> (rr, ri, ir, ii)

Exact rectangular derivative of nc_load_current: (∂i_r/∂v_r, ∂i_r/∂v_i, ∂i_i/∂v_r, ∂i_i/∂v_i). A real 2×2 block, since the current depends on |V| and is not holomorphic in V.

PowerfulYbus.calc_ybus_residuals! — Method
calc_ybus_residuals!(ws::ResidualBuffers, model::StructArray, external::NamedTuple,
                     network_sol::NetworkSolution, formulation::FormulationTrait,
                     model_to_gen_idx::Vector{Int}; active_mask)

Residuals of a machine with an internal voltage (network_partition_role(M) isa MachineWithInternalVoltage) at the Y-bus network solution: the terminal voltages v, theta of its in-service instances from network_sol (gather_terminal_voltages!), then the model's own residuals at them (calc_residuals!, those of the phasor TDS: flux and swing dynamics, stator current constraints, control inputs and power outputs).

model_to_gen_idx maps each model array index to its index among the network generators (0 when out of service). A machine model provides its Norton source to the network with get_machine_impedance and get_internal_voltage.

source
PowerfulYbus.gather_terminal_voltages! — Method
gather_terminal_voltages!(ws, network_sol, model_to_gen_idx, active_mask)

Set ws.var_vals.v and ws.var_vals.theta of each active generator from its terminal voltage network_sol.V_terminal[model_to_gen_idx[i]]. Inactive generators are not in the network generator set (model_to_gen_idx[i] == 0) and their residuals are masked, so they are skipped. Errors if an active generator is not in the set (e.g. it was put in service after the network was built).
