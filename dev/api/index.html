API Reference

Reference documentation for the public API of every Powerful.jl package, generated from the docstrings in the source code.

Powerful is the umbrella package: using Powerful brings in the public API of PowerfulCore, PowerfulPF and PowerfulTDS. PowerfulCA, PowerfulYbus and PowerfulCases are standalone packages that are loaded explicitly. Model types are imported from Powerful.Models.

Quick Start

using Powerful
using PowerfulCases

# Load a system and solve the power flow
sys = SystemModel(parse_network(load("ieee14").raw))
prob = ACPowerFlowProblem(sys)
sol = solve(prob, Newton())

# Access results by external key
v = get_var(sol, :Bus, :v, (1,))
