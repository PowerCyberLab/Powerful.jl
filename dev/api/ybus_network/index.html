NetworkCache(sys; T=Float64, V_pf=nothing)

Create a NetworkCache from system model.

PowerfulYbus.NetworkJacobian — Type
NetworkJacobian

Admittance matrix of one topology with the factorizations of its network equations: the complex matrix of the linear equations, or the real Newton Jacobian of the nonlinear ones (each built on first use).

Fields

  • Y::SparseMatrixCSC{ComplexF64,Int}: Admittance matrix of the topology
  • Y_fact: KLU factorization of Y with the Slack rows replaced by identity rows: the matrix of the linear network equations
  • J::SparseMatrixCSC{Float64,Int}: Real Jacobian work matrix (2n × 2n): the 2×2 block [G -B; B G] of each entry G + jB of Y (plus a structural diagonal block for every bus), with bus k at rows/columns 2k-1 (real part) and 2k (imaginary part); its values are rewritten when it is refactored. Empty until first needed
  • Y_nzval::Vector{Float64}: The values of J due to Y alone
  • diag::Vector{NTuple{4,Int}}: Indices into nonzeros(J) of the diagonal 2×2 block of each bus, ordered (rr, ri, ir, ii)
  • pv_rows, slack_rows::Vector{Vector{NTuple{2,Int}}}: For each static generator bus (StaticGeneratorBuses order), the indices into nonzeros(J) of its two rows, as (real row, imaginary row) pairs per stored column; the constraints replace them
  • fact: KLU factorization of J, reused across Newton steps and network solves while it keeps converging (see solve_network!)
  • refresh::Bool: Whether the next Newton step must rebuild and refactor J

PowerfulYbus.compute_electrical_power! — Method
compute_electrical_power!(P_e, Q_e, E_internal, V_terminal, E_buf)

Compute electrical power using stator current from terminal voltages.

Sign Convention (ANDES-compatible)

P_e is computed from the internal EMF perspective:

  • S = Einternal * conj(Istator)
  • P_e = real(S)

Sign interpretation:

  • P_e > 0: Generator producing power (E drives current into network)
  • P_e < 0: Generator absorbing power (current flows back into E)

This matches the ANDES convention where:

  • Generator injects power: appears as -P_e in bus power balance
  • For swing equation: Pm - Pe - D*(ω-1) = 2H * dω/dt

Physics

The stator current is:

  • Istator = (Einternal - Vterminal) / Zgen (positive = from E to V)

PowerfulYbus.solve_network! — Method
solve_network!(cache::NetworkCache{Float64}, sys; maxiters=50, abstol=1e-8)

Solve the network equations at every bus by Newton iteration.

This solve serves the EliminatedNetwork treatment of the DAE residual (YBusResidual), the baseline the simultaneous treatment is compared with, and the tests of the network solver. The fixed-step integration (solve_trapezoidal) and the DAE integration with the network simultaneous solve the network together with the models' algebraic rows (solve_algebraic!).

Equations

With the bus voltages V, KCL at every bus is

F(V) = Y V - I_E - I_inj(V) = 0

where Y is the sparse admittance matrix (lines, transformers, shunts, constant-impedance loads and generator admittances), I_E the generator Norton currents E/Zgen at the generator buses, and `Iinjthe nonlinear injections: minus the constant-power and constant-current load currents (calcloadcurrent) and plus the current-source currents (source_current`). They depend on |V| and are not holomorphic, so the Newton iteration runs in rectangular coordinates with exact 2×2 derivative blocks. At a static generator bus F is the current the generator injects, and its two equations are replaced by the generator's constraints: Re(V F*) = Σ pg and |V|² = vs² (PV), or V = vs∠va (Slack).

Without nonlinear injections or PV buses the equations are linear and holomorphic: they are solved directly, Y V = I_E with the Slack rows as identity rows, by the complex sparse LU factorization kept per topology (iterations = 1, residual = 0: exact up to round-off, not re-evaluated).

Iteration (nonlinear equations)

The iteration starts from the previous solution. Each step solves J Δ = r for the equation residual r (sparse KLU) and takes the largest step V - α Δ (α = 1, 1/2, ...) that decreases ‖r‖² (Armijo backtracking). The factorization of J is kept across steps and network solves (factoring dominates the cost): it is rebuilt at the current iterate when a step with it contracts the residual by less than a factor of 10, or finds no decrease; a fresh J that finds no decrease ends the iteration. It stops when the max equation residual (current mismatch, or constraint residual at static generator buses) is below abstol (pu), or after maxiters steps; non-convergence is reported in the returned NetworkSolution (converged = false), which callers must check.

After the solve, generator currents are Igen = (E - Vterminal)/Z_gen.

ForwardDiff derivatives of the solution come from the Dual method solve_network!(cache::NetworkCache{<:Dual}, primal, sys).

PowerfulYbus.solve_network! — Method
solve_network!(cache::NetworkCache{D}, primal::NetworkCache{Float64}, sys;
               maxiters=50, abstol=1e-8) where {D<:ForwardDiff.Dual}

Network solution with ForwardDiff derivatives by the implicit function theorem.

primal (the Float64 cache sharing cache's topology cache) solves the network at the values of the Dual inputs: the generator internal voltages cache.E_buf.E_internal and the current-source currents cache.cs_buf. The derivatives are then one linear solve with the Jacobian J of the equation residual r at that solution:

dV = -J⁻¹ (∂r/∂E dE + ∂r/∂I_src dI_src)

obtained as the derivative part of one Newton step from the solution with zero voltage derivatives: the Dual residual there has ∂r/∂(E, I_src)·d(E, I_src) as partials. The voltage values are those of the primal solution. For linear network equations J is the complex matrix factored per topology (no new factorization); otherwise the real Jacobian at the solution is factored. The voltages of cache are set from primal on every call, so no derivative carries over from an earlier evaluation.

PowerfulYbus.get_internal_voltage — Method
get_internal_voltage(ws, model::StructArray{<:SubtransientMachine}, idx::Int) -> Complex

Get internal voltage for a GENROU, GENSAL or GENTPJ1 generator using V + Z*I formula.

The "internal voltage behind subtransient impedance" is computed from: E = Vterminal + Zgen * I_stator

where:

  • V_terminal = v * cis(theta) from algebraic variables
  • I_stator = (Id - j*Iq) * cis(delta - π/2) transformed to network frame

This approach uses values from the previous timestep, but is consistent with the machine model equations.

System Buffers

PowerfulYbus.YBusSystemBuffers — Type
YBusSystemBuffers{T, F}

System-level workspace for Y-bus TDS evaluation with metadata-driven discovery.

Uses closure pattern (like SystemBuffers) to avoid compilation explosion. Separates generators (need network currents) from controllers (standard evaluation).

Type Parameters

  • T: Float type (Float64, Float32, etc.)
  • F: FormulationTrait type (PowerInjection, etc.)

Fields

  • formulation::F: Formulation trait for type dispatch
  • generator_evaluators::Vector{Function}: Y-bus generators: (f,g,x,y,t,net_sol) -> nothing
  • internal_voltage_gatherers::Vector{Function}: Per machine model: (E,x,y) -> nothing, setting the internal voltages E[k] of its in-service instances (network generator order model_to_gen_idx)
  • controller_evaluators::Vector{Function}: Controllers: (f,g,x,y,t,V_bus) -> nothing
  • workspaces_by_name::Dict{Symbol, Any}: For debugging access
  • metadata_by_name::Dict{Symbol, Any}: For debugging access
  • models_by_name::Dict{Symbol, Any}: Model arrays for gatherinternalvoltages!
  • externals_by_name::Dict{Symbol, Any}: External parameters of each model (e.g. Mratio, its base over the system base, for the current sources)
  • model_to_gen_idx::Dict{Symbol, Vector{Int}}: Maps modelname → [modelidx → genbusesidx]
  • automaton_models::Vector{Symbol}: The models that declare automata (their workspaces hold an AutomatonState, run by the automaton runtime of PowerfulTDS)
  • status: Model name → in-service mask, read by the evaluators (and the automata)

Design

  • Zero hard-coding: Uses network_partition_role trait for discovery
  • Metadata-driven: Uses model_metadata() for structure
  • Type-erased closures: Each closure fully specialized internally
  • Allocation-free hot path: All memory pre-allocated during construction
  • One source of bus voltage: controller variables that are bus voltages (bus_voltage_inputs) are set from the network's bus voltages

Example

# Create Y-bus system buffers (computes gen index mapping internally)
sys_ws = YBusSystemBuffers(Float64, am, sys, PowerInjection(), tds_prob.init)

# Evaluation (with voltage reconstruction)
network_sol = solve_network!(cache, sys)
V_bus = cache.V_bus
evaluate_ybus_residuals!(sys_ws, dae, network_sol, V_bus, t)
source
PowerfulYbus.YBusSystemBuffers — Method
YBusSystemBuffers(::Type{T}, am::AddressManager, sys::SystemModel,
                  formulation::FormulationTrait, tds_init; automata=nothing) where T

Construct Y-bus system workspace with metadata-driven discovery.

The setpoints of every workspace (Eq0, Pm0, ...) are set from the TDS initialization tds_init (sync_ybus_setpoints!), so buffers of any number type built from the same initialization evaluate the same residuals.

Zero hard-coding: Uses network_partition_role trait to automatically discover which models are generators (MachineWithInternalVoltage) vs controllers (NotInYBusFormulation).

Arguments

  • T: Float type for calculations
  • am: AddressManager with formulation-specific addresses
  • sys: SystemModel containing model vectors
  • formulation: PowerInjection() (or others when implemented)
  • tds_init: TDS initialization (tds_prob.init) holding the setpoint values
  • automata: Model name → AutomatonState to share (optional; nothing: new ones), as automaton_states of another YBusSystemBuffers returns them: the workspaces of every number type, and the trapezoidal solver's and the DAE residual's, read the discrete state the automaton runtime sets in one

Returns

  • YBusSystemBuffers: Fully allocated workspace ready for Y-bus evaluation

Discovery Process

  1. Refuse a model without a declared role or with an unsupported one (check_ybus_support)
  2. Compute generator index mapping (modelidx → genbuses_idx) from sys.models
  3. Iterate all models in sys.models
  4. Check network_partition_role(model_type)
  5. If MachineWithInternalVoltage: create generator evaluator with calc_ybus_residuals!
  6. If NotInYBusFormulation: create controller evaluator with calc_residuals!
  7. If NonConformingLoad with state variables (e.g., REGCA1): create controller evaluator (current injection still handled by NC solver, but state residuals need evaluation)
  8. Others (FixedNetworkElement, StaticGenerator, pure algebraic NonConformingLoad): skip (handled by the Y matrix and the network solve)

PowerfulYbus.evaluate_ybus_residuals! — Method
evaluate_ybus_residuals!(sys_ws::YBusSystemBuffers, dae, network_sol, V_bus, t)

Evaluate all residuals using Y-bus network solution - ZERO ALLOCATION.

Algorithm

  1. Evaluate generators with their terminal voltages from the network solution (calcybusresiduals!)
  2. Evaluate controllers with standard evaluation (calcresiduals!), their bus voltage variables set from `Vbus`

Arguments

  • sys_ws: Y-bus system workspace
  • dae: DAE with (f,g,x,y) vectors (or just (g,y) for power flow)
  • network_sol: NetworkSolution with generator currents
  • V_bus: Bus voltages (complex) of the network solution
  • t: Current time

Performance

  • Zero allocation after initial construction
  • Type-stable dispatch via closures
  • Each closure is fully specialized internally

PowerfulYbus.is_bus_injection — Method
is_bus_injection(res_meta) -> Bool

Check if a residual is a bus power/current injection.

Bus injections (pinj, qinj) scatter to Bus power balance residuals, which are handled implicitly by the network solve (I = Y*E) in Y-bus formulation.

Used as a predicate for build_res_scatter_tuple to filter out bus injections at construction time, enabling zero-allocation scatter in the hot path.

Returns

  • true if source_model === :bus_group (network injection to bus)
  • false otherwise (internal residual or control signal to other models)

Examples

  • GENCLS.p_inj → source_model = :bus_group → true (skip in Y-bus)
  • TGOV1.tm → source_model = :generators → false (keep - governor control)
  • GENCLS.g_P_m → source_model = nothing → false (keep - internal)

Usage

# Pre-compute filtered scatter tuple at construction time
internal_scatter_tup = build_res_scatter_tuple(
    ws.res_addrs, ws.res_vals, metadata;
    skip = is_bus_injection
)

# Hot path: zero-allocation scatter using pre-computed tuple
scatter_res_add!(internal_scatter_tup, f, g, active_mask)
scatter_res_set!(internal_scatter_tup, f, g, active_mask)
