Validation and Small-Signal Analysis (PowerfulTDS)

Validation of the initialized state, eigenvalue analysis and linearization for frequency response, computed from an initialized time-domain simulation problem.

Initialization Validation

Residual validation check results.

Fields

  • max_alg_residual::Float64 - Maximum absolute algebraic residual
  • non_zero_diff::Vector{Tuple{UInt, Float64, Symbol, Symbol}} - (address, value, model, equation)
  • non_zero_alg::Vector{Tuple{UInt, Float64, Symbol, Symbol}} - (address, value, model, equation)
  • is_valid::Bool - True if all residuals below tolerance

PowerfulTDS.print_initialization_summary — Function
print_initialization_summary(prob::TDSProblem; io::IO=stdout, keys=nothing, vars=nothing, include_observable_vars=false)
print_initialization_summary(initial_states::NamedTuple, sys::SystemModel; io::IO=stdout, keys=nothing, vars=nothing)

Print summary tables of initialized dynamic model states.

For each dynamic model, displays a table with:

  • Instance identification columns (from get_key_name, splatted if composite)
  • State variable columns (delta, omega, E_q, etc.)
  • Output variables (Pe, Qe) if include_observable_vars=true (TDSProblem only)

Arguments

  • prob::TDSProblem or initial_states, sys - Source of initialization data
  • io::IO=stdout - Output stream
  • keys=nothing - Optional filter for specific instances
    • If nothing, shows all instances
    • If provided, only shows instances matching the specified keys
    • Format: Dict(:ModelName => [key1, key2, ...]) where keys match get_key_name format
  • vars=nothing - Optional filter for state variables to display
    • If nothing, shows all state variables
    • If provided, only shows specified variables
    • Format: Vector{Symbol} (e.g., [:delta, :omega])
  • include_observable_vars=false - Include output variables (Pe, Qe) by evaluating residuals (TDSProblem only)

Examples

# Show all instances
prob = TDSProblem(setup_tds(sol_pf, dynamic_models); tspan=(0.0, 10.0))
print_initialization_summary(prob)

# Show only specific GENCLS instances by composite key (BUS, ID)
print_initialization_summary(prob; keys = Dict(:GENCLS => [(1, "1"), (2, "1")]))

# Show only specific state variables
print_initialization_summary(prob; vars = [:delta, :omega])

# Include output variables (P_e, Q_e for GENCLS)
print_initialization_summary(prob; include_observable_vars = true)

# Combine filters: specific instances and specific variables
print_initialization_summary(prob;
    keys = Dict(:GENCLS => [(1, "1"), (2, "1")]),
    vars = [:delta, :omega])

# Direct from initial_states (advanced)
print_initialization_summary(initial_states, sys)

PowerfulTDS.print_validation_report — Method
print_validation_report(result::ResidualValidationResult; io::IO=stdout)

Print formatted TDS initialization validation report.

Displays maximum residuals and tables of non-zero residuals (violations). Useful for diagnosing initialization problems before running simulation.

Arguments

  • result::ResidualValidationResult: Validation result from validate_tds_initialization
  • io::IO=stdout: Output stream (default: stdout)

Output

  • If valid: Shows "✓ All residuals within tolerance" with max values
  • If invalid: Shows "✗ Non-zero residuals detected!" with tables listing violating equations (address, model, equation name, residual value)

Example

prob = TDSProblem(init; tspan=(0.0, 10.0))
result = validate_tds_initialization(prob)

if !result.is_valid
    print_validation_report(result)
    # ======================================================================
    # TDS Initialization Validation Report
    # ======================================================================
    # ✗ Non-zero residuals detected!
    #   Max differential residual: 1.23e-02
    #   Max algebraic residual:    5.67e-03
    # ...
end

See Also

  • validate_tds_initialization: Generate validation result
  • write_validation_report: Write report to file
source
PowerfulTDS.validate_tds_initialization — Method
validate_tds_initialization(adapter::TDSAdapter, am::AddressManager, t; atol=1e-6, max_show=20)
validate_tds_initialization(prob::TDSProblem; atol=1e-6, max_show=20)

Validate TDS initialization by checking that the DAE starts in steady state.

Evaluates the residuals at the initial time and checks the steady-state conditions g = 0 and f = M·rate: the rates are zero at an equilibrium, and those of the sinusoidal steady state otherwise (initial_rates(prob.init.steady_state)).

Methods

  • (adapter, am, t) - Use existing adapter, whose initial state is the state at t (the start of its problem, prob.tspan[1]; called by solve(; validate=true))
  • (prob) - Standalone validation (creates adapter internally)

Arguments

  • adapter::TDSAdapter - TDS adapter with initialized buffers
  • am::AddressManager - Address manager for residual lookup
  • prob::TDSProblem - Initialized TDS problem
  • atol::Float64 - Absolute tolerance for zero check (default: 1e-6)
  • max_show::Int - Maximum violations to include in result (default: 20)

Returns

ResidualValidationResult with diagnostics

Example

prob = TDSProblem(setup_tds(sol_pf, dynamic_models))
result = validate_tds_initialization(prob)

if !result.is_valid
    println("Max residual: ", result.max_alg_residual)
end

Eigenvalue Analysis

PowerfulTDS.EigenvalueResult — Type
EigenvalueResult{T}

Result of eigenvalue analysis containing eigenvalues, eigenvectors, participation factors, and stability statistics.

Fields

  • eigenvalues::Vector{Complex{T}} - Complex eigenvalues (μ)
  • right_eigenvectors::Matrix{Complex{T}} - Right eigenvectors (N), each column = one mode
  • left_eigenvectors::Matrix{Complex{T}} - Left eigenvectors (W)
  • participation_factors::Matrix{T} - Normalized participation factors |W| * |N|
  • state_names::Vector{Symbol} - Variable names for each state

Statistics

  • n_positive::Int - Count of eigenvalues with positive real part (unstable)
  • n_zeros::Int - Count of eigenvalues with near-zero real part
  • n_negative::Int - Count of eigenvalues with negative real part (stable)

Zero Mass Handling

  • zero_mass_indices::Vector{Int} - Indices of states with zero mass coefficient (reduced)
  • n_states::Int - Number of states after reduction

PowerfulTDS.compute_eigenvalues — Method
compute_eigenvalues(prob::TDSProblem; tol=1e-6, verbose=false) -> EigenvalueResult

Compute eigenvalues and participation factors for small-signal stability analysis.

The state matrix is computed from the DAE Jacobian at the initial steady-state point using the same AD infrastructure as TDS solve. States with zero mass coefficients are treated as pseudo-algebraic and reduced.

Arguments

  • prob::TDSProblem - Initialized TDS problem (from power flow solution)
  • tol::Float64 - Tolerance for classifying eigenvalues as zero (default: 1e-6)
  • verbose::Bool - Print progress information (default: false)

Returns

EigenvalueResult containing eigenvalues, eigenvectors, participation factors, and statistics

Example

# Create TDS problem from power flow
prob = TDSProblem(setup_tds(sol_pf, dyr); tspan=(0.0, 10.0))

# Compute eigenvalues
result = compute_eigenvalues(prob)

# Check stability
if result.n_positive > 0
    @warn "System has $(result.n_positive) unstable modes"
end

# Print report
print_eigenvalue_report(result)

Eigenvalue Sensitivities

PowerfulTDS.EigenvalueSensitivity — Type
EigenvalueSensitivity

Eigenvalues of the linearized TDS system and their derivatives with respect to model parameters.

Fields

  • eigen::EigenvalueResult: Eigenvalues, eigenvectors and participation factors at the operating point (as compute_eigenvalues)
  • parameters::Vector{Tuple{Symbol, Symbol, Int}}: (model, field, instance) of each parameter, in the order of the columns
  • dlambda::Matrix{ComplexF64}: dlambda[i, j] is the derivative of eigenvalue i (eigen.eigenvalues[i]) with respect to parameter j
source
PowerfulTDS.damping_ratio_sensitivity — Method
damping_ratio_sensitivity(s::EigenvalueSensitivity) -> Matrix{Float64}

Derivatives of the damping ratios ζ = -σ/|λ| of the eigenvalues λ = σ + jω with respect to the parameters, dζ = ω (σ dω - ω dσ) / |λ|³: zero for a real eigenvalue, undefined (NaN) for a zero eigenvalue.

source
PowerfulTDS.eigenvalue_sensitivity — Method
eigenvalue_sensitivity(sol_pf, dyn_models, params; config=SimConfig(),
                       formulation=PowerInjection(), addressing=NaturalAddressing(),
                       tol=1e-6, verbose=false) -> EigenvalueSensitivity

Eigenvalues of the TDS system initialized from the power flow sol_pf with the dynamic models dyn_models (as setup_tds), and their derivatives with respect to the parameters params: (model, field, instances) tuples of fields of the dynamic models, e.g. [(:SEXS, :K, 1:5), (:TGOV1, :R, [2])], one parameter per instance.

The power flow is held; the states and setpoints of the dynamic models follow the parameters through the initialization. Errors if a parameter is not a real field of one of dyn_models, is given twice, or enters the equations of another model through its external parameters.

Example

dyr = parse_dynamics(file(load("ieee14"), :dyr, variant = "genrou"), sys)
s = eigenvalue_sensitivity(sol_pf, dyr, [(:SEXS, :K, 1:5)])

# Least-damped oscillatory mode and the gradient of its damping ratio
λ = s.eigen.eigenvalues
osc = findall(>(0.1), imag.(λ))
i = osc[argmin(-real.(λ[osc]) ./ abs.(λ[osc]))]
dζ_dK = damping_ratio_sensitivity(s)[i, :]

Linearization and Frequency Response

PowerfulTDS.linearize — Method
linearize(prob::TDSProblem, inputs, outputs; verbose=false) -> StateSpace

Linearize a TDS problem about its steady-state operating point, returning a continuous-time state-space model for use with ControlSystemsBase.jl: frequency response (Bode, Nyquist plots), stability analysis, or controller design.

Arguments

  • prob::TDSProblem: a TDS problem already at equilibrium (e.g. prob.tspan[1], before any event).
  • inputs, outputs: each a Vector of (model_name, field_name, instances) tuples.
    • model_name, field_name: the model type and field, as Symbols — for example (:TGOV1, :pref0, ...) for a governor's power reference, or (:GENCLS, :omega, ...) for a classical machine's rotor speed. An input must be a setpoint parameter of the model (not a state variable); an output may be any variable: a differential state, a controller state with a zero time constant, or an algebraic variable, including a network quantity the model reads such as its terminal voltage :v.
    • instances: which model instances to use, as a range or vector of integer indices into that model's array (1-based). 1:1 selects the first instance; [1, 3, 5] selects three specific ones. To find the index for a particular bus or generator (rather than "the first one"), use PowerfulCore.get_index_by_key(prob.sys, :GENCLS, (bus_number, id)), which returns the array index for that external key.

Keyword Arguments

  • verbose::Bool: print progress (default: false)

Example

using ControlSystemsBase: bode, bodeplot

prob = TDSProblem(init; tspan=(0.0, 10.0))

sys = linearize(prob,
    [(:TGOV1, :pref0, 1:1)],    # input: first governor's power reference
    [(:GENCLS, :omega, 1:1)]    # output: first machine's rotor speed
)

frequencies = 10.0 .^ range(-2, 2, length=100)
mag, phase, w = bode(sys, frequencies)

Extended help

An output that is not one of the retained differential states is expressed through those states and the inputs (w = -(W⁻¹W_x x_r + W⁻¹W_u u), see reduce_zero_mass_states), so such an output carries a direct feedthrough term D.
