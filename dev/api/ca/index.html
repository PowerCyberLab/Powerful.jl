Contingency Analysis (PowerfulCA)

AC contingency analysis and DC screening with PTDF and LODF. PowerfulCA is a standalone package: load it with using PowerfulCA. Contingency and outage types (Contingency, BranchOutage, ...) are documented under Outages and Contingencies.

Module

PowerfulCA.PowerfulCA — Module

PowerfulCA - Contingency Analysis for Power Systems

This package provides AC and DC contingency analysis capabilities including:

  • Sequential and parallel AC contingency calculation (ACCC)
  • N-1 and N-k outage analysis
  • Violation reporting (voltage limits, branch overloads)

Usage

using Powerful
using PowerfulCases

sys = SystemModel(parse_network(load("ieee14").raw))

contingencies = [
    Contingency("LINE_1_2", [BranchOutage(1, 2, "1")]),
    Contingency("GEN_3", [GeneratorOutage(3, "1")]),
]

# Sequential solve
result = solve_accc(sys, contingencies)

# Parallel solve (uses all available threads)
result = solve_accc_parallel(sys, contingencies; verbose=true)

# Print violation report
print_accc_report(result)

AC Contingency Analysis

PowerfulCA.solve_accc — Method
solve_accc(sys::SystemModel, contingencies; kwargs...) -> NamedTuple

Sequential AC Contingency Calculation with infrastructure reuse.

Returns a named tuple with:

  • base: Base case PowerFlowSolution
  • contingencies: Vector of per-contingency results (name, converged, iterations, residualnorm, y, outofservice, singular); `outof_serviceholds the instances the contingency switched off by model, including the buses (:Bus`) and devices of islands it leaves without a slack bus

Keyword Arguments

  • abstol::Real=1e-8: Absolute tolerance for convergence
  • maxiters::Int=20: Maximum Newton iterations per contingency
  • damping::Real=1.0: Step damping factor
  • ordering::Symbol=:AMD: KLU fill-reducing ordering (:AMD, :COLAMD, :natural)
  • verbose::Bool=false: Print progress

Example

using Powerful
using PowerfulCases

sys = SystemModel(parse_network(load("ieee14").raw))

contingencies = [
    Contingency("LINE_1_2", [BranchOutage(1, 2, "1")]),
    Contingency("GEN_3", [GeneratorOutage(3, "1")]),
    Contingency("N2_TEST", [BranchOutage(1, 2, "1"), GeneratorOutage(3, "1")]),
]

result = solve_accc(sys, contingencies; verbose=true)

for r in result.contingencies
    println("$(r.name): $(r.converged ? "OK" : "FAILED")")
end

See Also

  • solve_accc_parallel: Multi-threaded version for large contingency lists

PowerfulCA.solve_accc_parallel — Method
solve_accc_parallel(sys::SystemModel, contingencies; kwargs...) -> NamedTuple

Parallel AC Contingency Calculation using multi-threading.

Shares the base-case solution, topology and bus→device map across all threads, while each worker task owns a NewtonWorkspace with its own status dictionary, AD cache, Jacobian preparation, DAE vectors and factorization.

Arguments

  • sys::SystemModel: System model
  • contingencies: Vector of Contingency objects

Keyword Arguments

  • abstol::Real=1e-8: Absolute tolerance for convergence
  • maxiters::Int=20: Maximum Newton iterations per contingency
  • damping::Real=1.0: Step damping factor
  • ordering::Symbol=:AMD: KLU fill-reducing ordering (:AMD, :COLAMD, :natural)
  • verbose::Bool=false: Print progress

Returns

Named tuple with:

  • base: Base case PowerFlowSolution
  • contingencies: Vector of per-contingency results

Example

using Powerful
using PowerfulCases

sys = SystemModel(parse_network(load("ieee14").raw))

contingencies = [
    Contingency("LINE_1_2", [BranchOutage(1, 2, "1")]),
    Contingency("LINE_1_5", [BranchOutage(1, 5, "1")]),
    Contingency("LINE_2_3", [BranchOutage(2, 3, "1")]),
]

# Parallel solve using all available threads
result = solve_accc_parallel(sys, contingencies; verbose=true)

# Results
println("Processed $(length(contingencies)) contingencies using $(Threads.nthreads()) threads")
for r in result.contingencies
    status = r.converged ? "OK" : "FAILED"
    println("  $(r.name): $status ($(r.iterations) iters)")
end

Performance Notes

  • Set JULIA_NUM_THREADS environment variable before starting Julia
  • Typical speedup is near-linear up to 8-16 threads for large contingency lists
  • For small contingency counts (<10), sequential solve_accc may be faster due to threading overhead

See Also

  • solve_accc: Sequential version
  • Contingency: Contingency definition
  • BranchOutage, GeneratorOutage: Outage types

PowerfulCA.print_accc_report — Method
print_accc_report(result; vmin=0.95, vmax=1.05, rating=:rate_a)

Print ACCC report showing voltage and branch flow violations.

Instances a contingency switched off (out_of_service of its result) are not checked: an outaged branch carries no flow, and the buses of an island the contingency de-energized are listed as isolated instead of as voltage violations.

Arguments

  • result: Output from solve_accc
  • vmin: Low voltage limit in pu (default 0.95)
  • vmax: High voltage limit in pu (default 1.05)
  • rating: Rating set to use for branch limits (:ratea, :rateb, :rate_c)

Example

result = solve_accc(sys, contingencies)
print_accc_report(result; vmin=0.9, vmax=1.1)

PowerfulCA.screen_contingencies_dc — Method
screen_contingencies_dc(sys::SystemModel, contingencies; kwargs...) -> DCContingencyScreenResult

Fast DC contingency screening using LODF.

Estimates post-outage branch flows and identifies thermal limit violations without solving full power flow for each contingency.

Arguments

  • sys::SystemModel: System model
  • contingencies: Vector of Contingency objects

Keyword Arguments

  • loading_threshold::Real=100.0: Report violations above this loading (%)
  • use_lazy_ptdf::Bool=false: Use LazyPTDF for memory efficiency (large systems)
  • verbose::Bool=false: Print progress

Returns

DCContingencyScreenResult with base flows, per-contingency results, and critical contingencies.

Example

using Powerful
using PowerfulCases

sys = SystemModel(parse_network(load("ieee14").raw))

contingencies = [
    Contingency("LINE_1_2", [BranchOutage(1, 2, "1")]),
    Contingency("LINE_1_5", [BranchOutage(1, 5, "1")]),
    Contingency("LINE_2_3", [BranchOutage(2, 3, "1")]),
]

result = screen_contingencies_dc(sys, contingencies; verbose=true)

# Show critical contingencies
for idx in result.critical_contingencies
    r = result.results[idx]
    println("$(r.name): $(length(r.violations)) violations, max loading $(round(r.max_loading, digits=1))%")
end

Algorithm

  1. Solve DC power flow to get base case flows
  2. Compute the PTDF matrix (or use LazyPTDF)
  3. For each contingency:
    • Shift each lost generator's output to the slack through its PTDF column
    • Remove the outaged branches with the multiple-outage LODF (see file header)
    • Check for thermal violations
  4. Return results sorted by severity

Limitations

  • The slack bus picks up all lost generation
  • Uses DC power flow approximation (assumes flat voltage profile)
  • Thermal limits use Rate A (normal operation)

See Also

  • solve_accc: Full AC contingency calculation
  • estimate_post_outage_flows: Single contingency flow estimation

Power Transfer Distribution Factors

PowerfulCA.LazyPTDF — Type
LazyPTDF{T}

Lazy/virtual PTDF that computes rows or columns on demand.

For large systems, storing the full PTDF (L x N) is expensive. LazyPTDF stores only the factorization and computes entries as needed.

Fields

  • F: KLU factorization of reduced B matrix
  • A::SparseMatrixCSC{Int8, Int}: Incidence matrix
  • b::Vector{T}: Branch susceptances (1/x)
  • slack_bus::Int: Slack bus index
  • non_slack::Vector{Int}: Non-slack bus indices
  • branch_indices::Vector{Tuple{Symbol, Int}}: Branch model mapping
  • row_cache::Dict{Int, Vector{T}}: Cached PTDF rows
  • col_cache::Dict{Int, Vector{T}}: Cached PTDF columns

Example

lptdf = LazyPTDF(sys)

# Get PTDF row for branch 5 (on-demand computation)
row = get_ptdf_row(lptdf, 5)

# Get PTDF column for bus 10
col = get_ptdf_column(lptdf, 10)

PowerfulCA.PTDF — Type
PTDF{T}

Power Transfer Distribution Factor matrix: matrix[l, k] is the change in flow on branch l per unit (1 pu, i.e. 1 MW at the system base) of injection at bus k, with the slack bus absorbing the balance.

Fields

  • matrix::Matrix{T}: dense L x N PTDF matrix
  • branch_indices::Vector{Tuple{Symbol, Int}}: branch model mapping
  • slack_bus::Int: slack bus internal index (reference)

Both l and k are internal array indices (1-based positions in the branch and bus arrays), not the bus numbers or branch keys from the raw case data. A bus's internal index can only be read back from a bus number with PowerfulCore.get_index_by_key(sys, :Bus, (bus_number,)).

Usage

ptdf = compute_ptdf(sys)
flow_change = ptdf.matrix[branch_idx, bus_idx] * injection
source
PowerfulCA.compute_ptdf — Method
compute_ptdf(sys::SystemModel; slack_bus::Union{Int, Nothing}=nothing) -> PTDF

Compute the full PTDF matrix for a system.

Arguments

  • sys::SystemModel: System with topology analyzed
  • slack_bus::Union{Int, Nothing}: Slack bus internal index (default: from topology)

Returns

PTDF struct containing L x N dense matrix.

Algorithm

  1. Build B matrix from incidence: B = A' * D * A
  2. Remove slack bus row/column to make B invertible
  3. Factorize reduced B using KLU sparse solver
  4. For each bus k, solve B * thetak = ek
  5. Compute PTDF[:, k] = D * A * theta_k

Example

sys = SystemModel(parse_network(load("ieee14").raw))
ptdf = compute_ptdf(sys)

# Flow change on branch 3 from 1 MW injection at bus 5
delta_flow = ptdf.matrix[3, 5] * 1.0

Line Outage Distribution Factors

PowerfulCA.LODF — Type
LODF{T}

Line Outage Distribution Factor matrix.

Fields

  • matrix::Matrix{T}: Dense L x L LODF matrix
  • branch_indices::Vector{Tuple{Symbol, Int}}: Branch model mapping

Usage

Convenience method: compute LODF directly from system.

source
PowerfulCA.compute_lodf — Method
compute_lodf(ptdf::PTDF, A::SparseMatrixCSC{Int8}) -> LODF

Compute LODF matrix from PTDF and incidence matrix.

Arguments

  • ptdf::PTDF: Pre-computed PTDF matrix
  • A::SparseMatrixCSC{Int8}: Branch-bus incidence matrix

Returns

LODF struct containing L x L dense matrix.

Algorithm

H = PTDF * A'           # L x L: sensitivity of flow l to injection pattern of branch m
h = diag(H)             # Self-sensitivity
LODF[m, l] = H[m, l] / (1 - H[l, l])  for m ≠ l
LODF[l, l] = -1         # Outaged line loses all flow

Example

ptdf = compute_ptdf(sys)
A, _ = build_incidence_matrix(sys)
lodf = compute_lodf(ptdf, A)

# Check: when line 3 outages, how much flows to line 5?
redistribution_fraction = lodf.matrix[5, 3]
