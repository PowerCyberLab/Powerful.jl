Report Customization

This guide shows how to generate result tables and text reports from power flow solutions, with control over units, formatting, and column selection.

The Basic Workflow

using Powerful
using PowerfulCases
using DataFrames

sys = SystemModel(parse_network(load("ieee14").raw))
sol = solve(ACPowerFlowProblem(sys), Newton())

bus_data = collect_model_table(sol, :Bus)

collect_model_table(sol, :Model) returns a NamedTuple of columns: the instance key columns, then the model's outputs, then its parameters. It works with any Tables.jl consumer (DataFrames, CSV, ...). The default configuration gives:

  • Power in MW/MVAR
  • Voltage magnitudes in per-unit
  • Angles in degrees
  • Column names with units

Understanding Report Configuration

Reports are controlled by ReportConfig, which has three parts:

config = ReportConfig(
    units = UnitPreferences(power = :physical, voltage = :pu),
    formatting = FormattingPreferences(float_precision = 4),
    columns = ColumnPreferences(include_id = true, use_descriptions = true),
)

Pass it with the config keyword:

collect_model_table(sol, :Bus; config = config)
print_model_table(sol, :Bus; config = config)

1. Unit Preferences

UnitPreferences(
    power = :physical,      # :physical (MW/MVAR) or :pu
    voltage = :pu,          # :pu or :kv
    angle = :deg,           # :deg or :rad
    impedance = :pu,        # :pu or :ohm
    base_mva = 100.0,       # System base power
)

The values shown are the defaults.

2. Formatting Preferences

FormattingPreferences(
    float_precision = 4,    # Decimal places
)

Formatting applies to printed tables (print_model_table, text reports). collect_model_table always returns full precision for data export.

3. Column Preferences

ColumnPreferences(
    use_descriptions = true,      # Descriptive names vs. field names
    include_units = true,         # Append units, e.g. "(MW)"
    column_style = :short,        # :compact, :short, :verbose
    include_id = true,            # Include the key columns
    include_vars = nothing,       # Vector{Symbol}: select specific outputs
    exclude_vars = Symbol[],      # Exclude these outputs
    include_params = true,        # Include model parameters
    exclude_params = Symbol[],    # Exclude these parameters
)

Column styles:

for style in (:compact, :short, :verbose)
    style_config = ReportConfig(columns = ColumnPreferences(column_style = style))
    println(style, ": ", keys(collect_model_table(sol, :Branch; config = style_config)))
end
compact: (:I, :J, :Ckt, :P_from, :Q_from, :P_to, :Q_to)
short: (:I, :J, :Ckt, Symbol("P_from (MW)"), Symbol("Q_from (MVAR)"), Symbol("P_to (MW)"), Symbol("Q_to (MVAR)"))
verbose: (:I, :J, :Ckt, Symbol("Active power flow from bus i (computed) (MW)"), Symbol("Reactive power flow from bus i (computed) (MVAR)"), Symbol("Active power flow from bus j (computed) (MW)"), Symbol("Reactive power flow from bus j (computed) (MVAR)"))

Working with Parameters

Model parameters with unit metadata are included after the outputs. For loads, these are the constant-power, constant-current, and constant-admittance components:

keys(collect_model_table(sol, :PQ))
(:I, :Id, Symbol("P_consumed (MW)"), Symbol("Q_consumed (MVAR)"), Symbol("Pl (MW)"), Symbol("Ql (MVAR)"), Symbol("Ip (MW)"), Symbol("Iq (MVAR)"), Symbol("Yp (MW)"), Symbol("Yq (MVAR)"))

Exclude All Parameters

config = ReportConfig(columns = ColumnPreferences(include_params = false))
keys(collect_model_table(sol, :PQ; config = config))
(:I, :Id, Symbol("P_consumed (MW)"), Symbol("Q_consumed (MVAR)"))

Exclude Specific Parameters

The bus parameters vm and va are the voltages from the case file (the initial guess). Default excludes them; other configurations include them unless excluded:

keys(collect_model_table(sol, :Bus; config = AllPhysical))
(:I, Symbol("Theta (deg)"), Symbol("V (kV)"), Symbol("Vm (pu)"), Symbol("Va (deg)"))
config = ReportConfig(AllPhysical; columns = ColumnPreferences(exclude_params = [:vm, :va]))
keys(collect_model_table(sol, :Bus; config = config))
(:I, Symbol("Theta (deg)"), Symbol("V (kV)"))

Formulations

Reports read bus voltages through bus_voltages(sol), which gives the magnitude and angle of every bus in any formulation, so a CurrentInjection solution reports the same tables as a PowerInjection one. A DCPowerFlow solution reports what the DC model solves: bus angles and active power; the voltage magnitude and reactive power columns are left out. Devices that are out of service report no flow or consumption.

Unit Conversion

Reports convert values in two ways:

  • Model parameters use the per-unit coefficients stored when the system was built (sys.pu_coeffs): physical = per-unit / coefficient. This is the exact inverse of the conversion at load time.
  • Computed outputs (flows, injections, angles) are converted by their unit type: power × base_mva for MW/MVAR, radians to degrees, and per-unit voltage × the bus base voltage (Bus.basekv) for kV.
