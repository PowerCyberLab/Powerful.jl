Multi-Island Systems

A network can split into several electrically disconnected parts (islands), for example after branch outages. Powerful.jl detects islands when a power flow problem is created and solves each island separately.

This guide uses the two-island variant of the IEEE 14-bus case, in which buses 1-6 and buses 7-14 are not connected.

Detecting Islands

using Powerful
using PowerfulCases

raw = file(load("ieee14"), :raw; variant = "island")
sys = SystemModel(parse_network(raw))

topo = analyze_topology(sys)
topo.n_islands
2

analyze_topology returns a TopologyInfo with the connectivity of the network, including the number of islands, the island of each bus (topo.island_map, by internal bus index), and the buses of each island (topo.components).

split_islands builds one SystemModel per island. For a connected system it returns the original SystemModel:

islands = split_islands(sys)

for (k, island) in enumerate(islands)
    println("Island $k: buses ", Int.(sort(island.models.Bus.i)),
            ", slack bus ", Int.(island.models.Slack.i))
end
Island 1: buses [1, 2, 3, 4, 5, 6], slack bus [1]
Island 2: buses [7, 8, 9, 10, 11, 12, 13, 14], slack bus [8]

Each island needs its own slack bus (bus type 3) to fix its voltage angle and supply its losses. An island without one is reported with a warning and does not converge.

Solving

Create the problem and solve as for a connected system:

prob = ACPowerFlowProblem(sys)
ACPowerFlowProblem:
  Formulation: PowerInjection
  Islands: 2

sol = solve(prob, Newton())
MultiIslandSolution{Float64}:
  Islands: 2
  Converged: 2/2
  Max iterations: 4
  Max residual: 1.46e-9
  Total variables: 28

ACPowerFlowProblem detects the islands and solve solves each one. For a system with more than one island, the result is a MultiIslandSolution:

  • sol.converged is true only if every island converged
  • sol.iterations and sol.residual_norm are the largest over the islands
  • sol.islands holds the island systems and sol.solutions their PowerFlowSolutions
[(converged = s.converged, iterations = s.iterations) for s in sol.solutions]
2-element Vector{@NamedTuple{converged::Bool, iterations::Int64}}:
 (converged = 1, iterations = 4)
 (converged = 1, iterations = 4)

Accessing Results

get_var, get_all_vars, and get_vars_dict work on a MultiIslandSolution as on a single solution. get_var finds the island that holds the key:

v1 = get_var(sol, :Bus, :v, (1,))          # Bus 1, in island 1
v14 = get_var(sol, :Bus, :v, (14,))        # Bus 14, in island 2
(v1, v14)
(1.03, 0.9497048961425368)
θ = get_vars_dict(sol, :Bus, :theta)       # All buses of all islands
rad2deg(θ[(1,)]), rad2deg(θ[(8,)])
(0.0, -1.3945)

Each island has its own angle reference: the angle of its slack bus (buses 1 and 8 here) is fixed at the value in the case file.

get_all_vars concatenates the values of the islands in island order:

length(get_all_vars(sol, :Bus, :v))
14

Solving Islands Individually

For control over each island, for example to pass an initial guess, build one problem per island:

solutions = [solve(ACPowerFlowProblem(island), Newton()) for island in islands]

get_var(solutions[2], :Bus, :v, (14,))
0.9497048961425368

An initial guess (initial_guess keyword) is supported only for a single island, since each island has its own variable layout.

Disabling Island Detection

With auto_split = false, the whole system is solved as one problem without splitting:

prob_whole = ACPowerFlowProblem(sys; auto_split = false)
sol_whole = solve(prob_whole, Newton())
get_var(sol_whole, :Bus, :v, (14,))
0.9497048961425368

This requires every island to have a slack bus, as the solution above does.
