User Guides

Task-oriented guides for using Powerful.jl.

Getting Started

New to Powerful.jl? Start here:

  • Getting Started - The basic workflow and key concepts
  • Power Flow Analysis - Formulations, algorithms, and options
  • Accessing Results - Reading solution variables and result tables
  • Report Customization - Units, columns, and presets for result tables
  • Multi-Island Systems - Detecting and solving disconnected networks

Studies

  • Time-Domain Simulation - Dynamic simulation and transient analysis
  • Eigenvalue Analysis - Small-signal stability and mode analysis
  • Frequency Response - Linearization and Bode plots
  • DC Analysis - DC power flow, PTDF/LODF, and DC contingency screening
  • Contingency Analysis - N-1 and N-k AC contingency analysis
  • Y-Bus Simulation - Time-domain simulation with a sparse Y-bus network solution

Additional Topics

  • Models - Available static and dynamic models
  • Configuration - System, model, and solver settings via TOML or code
  • Automatic Differentiation - Derivatives of power flow and simulation results

Learning Path

  1. Beginners: Read Getting Started to understand SystemModel, problems, and solutions
  2. Intermediate: Study Power Flow Analysis and Accessing Results
  3. Dynamics: Learn Time-Domain Simulation, then Eigenvalue Analysis and Frequency Response
  4. Security: Use Contingency Analysis and DC Analysis for N-1/N-k assessment
  5. Reference: Use the API Reference for complete function documentation

Note: These guides focus on how to accomplish tasks. For complete API details, see the API Reference. For implementation details, see the Developer Documentation.
